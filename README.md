# Infinite Commute

> Infinite Commute: game app for pets.

A one-month game project called Infinite Commute — for pets. Built fast, shipped faster.

## Features
- Core game loop that works in under 10 seconds of use
- The twist: for pets
- Zero-setup onboarding — useful within one minute
- Share/export so friends can join or compete

## Stack
- Bevy
- SQLite
- TypeScript

## Getting started
```
cargo run --release (SQLite auto-creates local DB; optional npm install && npm run build for TypeScript share/export)
```
